Um único pacote de aplicativos para produtos verticais do Autodesk AutoCAD.

Ferramentas para filtragem, revisão de modelos, produção de desenhos e muito mais.

### Incluído no pacote DiRootsOne
- OneFilter
Encontre rapidamente elementos no AutoCAD, Civil 3D, Advance Steel, AutoCAD Plant 3D, AutoCAD Architecture, AutoCAD Electrical, AutoCAD MEP, AutoCAD Map 3D, AutoCAD Mechanical etc. Pesquise por camada, tipo de objeto e propriedades. Use regras condicionais avançadas para restringir os resultados.

- SheetGen (Em breve)

### Produtos verticais do AutoCAD compatíveis:
AutoCAD, Civil 3D, Advance Steel, AutoCAD Plant 3D, AutoCAD Architecture, AutoCAD Electrical, AutoCAD MEP, AutoCAD Map 3D, AutoCAD Mechanical etc.

### Versões compatíveis do AutoCAD
2021, 2022, 2023, 2024, 2025, 2026, 2027.
