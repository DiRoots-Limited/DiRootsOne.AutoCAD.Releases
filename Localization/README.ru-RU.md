Единый пакет приложений для отраслевых продуктов Autodesk AutoCAD.

Инструменты для фильтрации, проверки моделей, выпуска чертежей и других задач.

### В пакет DiRootsOne входят
- OneFilter
Быстро находите элементы в AutoCAD, Civil 3D, Advance Steel, AutoCAD Plant 3D, AutoCAD Architecture, AutoCAD Electrical, AutoCAD MEP, AutoCAD Map 3D, AutoCAD Mechanical и других продуктах. Ищите по слою, типу объекта и свойствам. Используйте расширенные условные правила для уточнения результатов.

- SheetGen (Скоро)
